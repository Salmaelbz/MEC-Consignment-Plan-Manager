# MEC Consignment Plan Manager

A lightweight browser-based workflow for processing PDF consignment plans and matching them with Excel reference data.

## Features
- Upload PDF files or ZIP archives
- Upload a reference Excel file
- Upload an updated energy sheet
- Configure processing options
- Simulate matching and final output generation
- Download generated PDF and Excel output bundles

## Run locally
1. Open `index.html` in a browser.
2. Upload the required files.
3. Configure the processing options.
4. Start processing and download the result files.

## Project structure
- `index.html` — single-page app

## Notes
